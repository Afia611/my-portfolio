💻 Getting Started
To run this portfolio locally:
1. Clone the repository
git clone https://github.com/Afia611/my-portfolio.git
cd my-portfolio
If your GitHub repository has a different name, replace the clone URL accordingly.

2. Install dependencies
npm install
3. Start the development server
npm run dev
Open http://localhost:3000 in your browser.
4. Create a production build
npm run build
npm run start
